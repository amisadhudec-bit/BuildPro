# 🏗️ BuildPro – Construction Company Website  

BuildPro is a modern, responsive **Construction Company Website** built using **HTML, CSS, Bootstrap, and JavaScript**.  
This project showcases a professional landing page for a construction business with a hero slider, services section, about page, achievements counters, testimonials, locations with Google Maps, newsletter subscription, and smooth animations using AOS.  

Perfect for frontend portfolios and real-world business website layouts.  

---

## 🌟 Features  

- Fully Responsive Design  
- Bootstrap 5 Layout  
- Hero Carousel Slider  
- Animated Sections (AOS)  
- Services Cards with Hover Effects  
- About & Team Sections  
- Achievements Counter Animation  
- Testimonials Section  
- Google Maps Integration  
- Newsletter Subscription UI  
- Social Media Icons  
- Modern Footer Design  

---

## 🛠️ Technologies Used  

- HTML5  
- CSS3  
- Bootstrap 5  
- JavaScript  
- AOS Animation Library  
- Animate.css  
- Bootstrap Icons
